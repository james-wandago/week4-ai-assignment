## Question 1: what is Data
Data is raw facts or information that can be processed to get useful meaning.

## Question 2: Difference between structured and unstructured Data
1) Structured Data, is type of data that is organised in rows and columns like in a spreadsheet.
2) unstructured data, is a type of data which is not organised,can be an audio,video,pictures or text document.

## Question 3: What is data set
